# BARadar 界面设计系统

断箭蛐工具（BARadar）的桌面端与浏览器预览共用这套规则。本文只记录跨页面的设计约束；具体页面的交互流程、业务计算和参数以[功能源码](../../apps/web/src/features)为准。

## 组件与样式

- 优先组合[共享 shadcn/ui 组件](../../apps/web/src/components/ui)及其变体。页面负责布局；需要新的表面或控件样式时，先扩展共享组件，不在调用处覆盖材质、阴影或圆角。
- 在 React 的 `className` 中使用 Tailwind CSS v4 工具类，用 `cn()` 组合条件类名。运行时尺寸通过 CSS 变量传入，不用选择器或成组的 `@apply` 重建页面样式表。
- 手写 CSS 仅用于共享 token、浏览器与原生窗口基础样式、共享布局计算、Shadow DOM 宿主，以及强制颜色和减少动态效果等全局适配。新增例外须说明为什么不能放在基础组件中。

## 颜色与表面

- 组件按语义使用[主题 token](../../apps/web/src/styles/index.css)。明暗模式和调色板不得改变状态含义。ELO 涨跌遵循用户的配色偏好，不借用胜负或成功／错误的语义。
- 工作区和桌面导航使用平坦背景。独立内容组使用共享玻璃卡片；卡片内的行用间距或分隔线分组，不为制造留白再套一层卡片。表格及固定单元格默认透明；用裁剪而不是额外的底色遮住滚入固定区域的文字。
- 卡片和浮层复用[共享玻璃材质](../../apps/web/src/lib/surfaces.ts)。提示表面沿用卡片填充；菜单、对话框等浮层使用可读性更高的浮层填充。嵌套卡片保留玻璃填充，但仅外层卡片应用背景滤镜。玻璃不透明度只作用于填充，不连带淡化内容。带背景滤镜的悬停提示保持静止，避免动画留下残影。
- 不用渐变、高光叠层或彩色边缘光装饰工作区。媒体可使用中性底色，配色预览可展示色样，品牌标志保留原色；这些例外不延伸到外层卡片。

## 几何与布局

- 按面板、控件、徽章等角色选择共享圆角，不按元素宽度选圆角。使用连续曲率时，将圆角半径和 `corner-shape: squircle` 设在同一个绘制边框或裁剪内容的元素上。相邻的嵌套圆角保持同心：**外圆角 = 内圆角 + 内外边缘间距**。间距计入边框，不计焦点环；贴边内容由父元素裁剪。
- 卡片之间统一使用 `--content-gap`；窄布局优先换行或堆叠，不压缩卡间距和操作目标。同组控件使用同一高度档位，图标大小与命中区域分别处理。
- 面板按实际可用宽度布局，优先使用容器查询；只有依赖窗口本身的布局才用视口断点。为原生标题栏控件留出空间。长名称允许换行或截断，完整内容仍须可访问；宽表在自身容器内滚动，不撑宽页面。
- 用标题、分组、对齐和间距表达层级，不重复面包屑已有的页面名称或同一项说明。沿用共享字体与图标；供比较的数字使用等宽数字，表格中的数值按列对齐。

## 数据状态与无障碍

- 区分加载、缺失、空结果、零值和错误。结构已知时在数据最终位置放置占位，预留表头和媒体空间；后台刷新保留仍然有效的内容与用户上下文，不用整页骨架替换。
- 使用具有正确语义的交互元素，不嵌套按钮。控件须可通过键盘操作，有可见焦点和本地化的无障碍名称；选择、禁用和忙碌状态不能只靠颜色或动画表达。浮层内的操作须能用键盘完成；关闭后将焦点还给触发控件或新的导航目标。
- 在实际合成背景上检查对比度：普通正文至少 **4.5:1**，用于识别焦点或选中状态的关键边界至少 **3:1**。强制颜色模式使用系统色；减少动态效果时仍须能辨认当前状态。
- 按用户实际看到的尺寸验证布局，覆盖明暗主题、不同玻璃不透明度、中英文长内容及非整数显示缩放。尺寸与布局变量见[共享布局样式](../../apps/web/src/styles/layout.css)，检查要求见[仓库指引](../../AGENTS.md#validation)。
