## Changes

- Make the Maggot Index easier to read with a labeled 0–10 scale, score marker,
  trend indicator, sample explanation, and calculation progress. Preserve the
  card layout while data loads or refreshes.
- Let match archives, scoreboards, player reports, and ban tables reveal the
  surrounding glass surface. Keep sticky headers and identity columns readable
  while scrolling, with shared clipping that prevents overlapping content.

## Downloads

- `BrokenArrow-Setup-4.5.9-x64.exe`: Windows x64 installer.
- `BrokenArrow-Portable-4.5.9-x64.exe`: Windows x64 portable application.
- `latest.yml` and the `BrokenArrow-Setup-4.5.9-x64.exe.blockmap` file support
  application updates.
