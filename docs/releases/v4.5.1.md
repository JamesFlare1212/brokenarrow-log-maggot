## Changes

- Add adjustable frosted glass cards and unify their surfaces, corners, and
  selection states across the interface.
- Redesign player profiles with automatic Maggot Index analysis, combat
  preferences, encounter history, and map performance. Keep profile refresh in
  the dialog header beside Close.
- Add a match archive grid with ELO change badges, and fix overlapping archive
  filters and actions at narrow window widths.
- Reuse the Alpha roster for pre-match parties and preserve the standard 5v5
  panel height across empty, lobby, and match states.
- Add developer previews for pre-match parties with 1–5 players.
- Compact APM history and capture details, hide secondary dashboard text when
  space is limited, and improve sidebar footer spacing.
- Keep dialogs clear of native window controls and update appearance values
  immediately when reduced motion is enabled.
- Document the current glass design system, remove outdated guidance, and add
  repeatable UI design and local documentation link checks.
