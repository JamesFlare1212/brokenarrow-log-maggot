## Changes

- Add an ELO trend chart covering up to 30 recent matches in player profiles,
  with match details, period changes, and gaps for unavailable ratings.
- Replace the player report's map table with responsive performance cards showing
  match counts, win rates, average K/D, and average destruction scores.
- Show all reported preferred units and categories, including deployment counts,
  ROI, and category spending, with stable layouts while reports load.
- Add consistent loading placeholders across the application. Preserve table
  columns, section layouts, and playback frames, and retain existing data during
  refreshes and refresh failures.
- Protect manually named deck backups from accidental replacement while keeping
  the managed previous-match backup up to date.
- Give each recording attempt its own session identity so delayed messages from
  an earlier capture cannot affect a new recording of the same match.
- Remove APM tracking and input monitoring, including obsolete settings, saved
  navigation entries, and input-statistics tables.
